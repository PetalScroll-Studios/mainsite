### YouTube Video Backup Advice
- **Easiest method:** Use `yt-dlp` (command line) — free, open-source, no account needed
  ```
  yt-dlp -f best https://www.youtube.com/@StarTrekNotStarWars/videos
  ```
- **After deletion on YouTube:** A "shell" (thumbnail, title, description, comments) can persist for **weeks to months** — there's no guaranteed timeline. The video itself is gone immediately, but metadata/URLs may remain indexed by Google/cache. Full removal from all caches/CDNs can take **30-90 days**.

**Current state:** You have a static `blog.html` with placeholder posts. You also have Discord, GitHub, Reddit, YouTube, and Twitch available.

**My recommendation: Use multiple channels, not a blog on this site.**

| Channel | Best For | Why |
|---------|----------|-----|
| **GitHub** | Dev updates, technical docs, changelogs | You're already there; issues/discussions are natural blog format for dev work |
| **Discord** | Community interaction, real-time updates | Best for engagement; create a #dev-updates channel |
| **YouTube** | Video devlogs, tutorials | Visual medium for game dev is powerful |
| **Reddit** | Broader reach, feedback | r/gamedev, r/roblox, r/indiedev are active communities |
| **This website** | Portfolio hub, links to everything | Keep it as a landing page that links OUT to your content elsewhere |

**Suggestion:** Remove or deprioritize `blog.html` — maintain this site as a portfolio hub. Post devlogs on GitHub Discussions or a Discord #dev-updates channel, and link to them from here. Reddit is good for discoverability but not as a primary blog. Video blogs (YT) are great for game dev — consider that route.
