# Dashboard Fixes — Plan

## Issues to Fix

### 1. Calendar Panel — Fill Available Space (Scrollable)

**Problem:** Calendar iframe has fixed 600px height, panel isn't scrollable, blocks other content.

**Fix:**
- Make `.dashboard-main` and `.dashboard-panel` fill viewport height with `overflow-y: auto`
- Calendar iframe uses `height: 100%` or `flex: 1` to fill available space
- Remove the fixed 600px height
- Ensure panels are scrollable when content exceeds viewport

### 2. AI Services — Keep as Launch Buttons

**Problem:** User wants AI services loaded in iframes, but they're blocked by `X-Frame-Options` headers.

**Fix:** Keep current approach — sidebar click shows info panel with "Open in new tab" button. This is the only option for a static site without a server proxy.

### 3. Private Dashboard — Panel Visibility

**Problem:** Calendar stays visible, other panels don't show.

**Fix:** Ensure `switchPanel()` properly hides all panels and shows only the selected one. Check CSS `.dashboard-panel` display rules.
