Local AI Setup

Hardware Requirements

Budget-Tier Setup

  • • 8-16GB RAM
  • • 4GB VRAM GPU
  • • 10-25GB free storage

Even a Raspberry Pi can run small models!

Mid-Tier Setup

  • • 16GB RAM
  • • 8GB VRAM GPU
  • • 50GB free storage

Recommended

  • • 32GB+ RAM
  • • 12GB+ VRAM GPU
  • • 100GB+ SSD storage

Step-by-Step Setup

1

Install LM Studio

Download and install LM Studio from the official website. Available for Windows, Mac, and Linux.

# Download from https://lmstudio.ai
# Follow installation instructions
2

Download Models

Browse and download models suitable for your hardware. Start with smaller models (4B-9B) if you have limited VRAM.

# Recommended starting models:
# - Gemma 4:e2b or e4b (General daily drivers, multiple flavors)
# - LFM2.5-8b-a1b (Great mid-range MOE model)
# - Qwopus 3.5-4b or 9b coders (Qwen coders cross-trained with Opus)
3

Configure Local Server

Start LM Studio's local server to make models available via API.

# Default endpoint:
http://localhost:1234/v1

# Compatible with OpenAI API format
4

Integrate with Development Tools

Configure your IDE and coding assistants to use the local API endpoint.

# Example: Configure MiMoCode
API_BASE_URL=http://localhost:1234/v1
MODEL_NAME=local-model
